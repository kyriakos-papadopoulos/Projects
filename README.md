## 🚀 Featured Projects

### **UTM Link Generator**
A small tool built to help colleagues generate clean, consistent UTM links for marketing campaigns.  
Eliminates manual errors and speeds up link creation.

**Tech:** Python, Regex, CLI automation

---

### **Data Science Bootcamp Projects**  
Projects developed as part of the Big Blue Data Academy program.

**Interactive Dashboard (Lung Cancer Dataset)**  
Explored patient risk factors and diagnoses.  
Delivered insights through an interactive dashboard.

**Clustering (Spotify Dataset)**  
Used Spotify’s top 2,000 tracks to identify song clusters based on audio features.  
Applied PCA for dimensionality reduction and KMeans for grouping.

### **API Projects**

#### **Spotify**
**Text-to-Playlist:**  
Creates a playlist from a user-written sentence by matching words to song titles via the Spotify API.

**Monthly Playlists:**  
Generates monthly personalized playlists and creates custom playlist covers automatically.

**Tech:** Python, Spotipy, PIL, automation
